
# 交易本质

## 核心
交易的本质非常简单，就是胜率加盈亏比，这是所有交易盈利的基石，如果你不能认可这个，那么会走非常多的弯路。

道理都懂，为什么还是那么多人在交易上赚不到钱呢？我怎么知道这一笔交易的胜率是多少？设置的盈利价位是否符合我估出来的胜率？

而市场波动又是随机的，看到这你一定发现出现了自我矛盾的点，为什么是随机的，还能盈利？

这里的随机是指市场没有100%的概率，你觉得大概率的事件也有失败的概率，认清这个，你算进入交易的门槛了。

任何交易分析，一定是你有基本的技术分析能力才能立足，需要有下次出现同样的行情有继续复刻的能力，如果你是根据盘感交易，那么这些优势都不存在了。

## 怎么寻找胜率？
一个品种有世界五花八门的人在上面做交易，当大多数资金都认可买入就上涨，认可卖出就下跌，就是这么简单。

在我的认知中，交易不等同于投资，所以不考虑背景和新闻，而是从图表k线上找线索，就算是新闻面冲击，在图表上也能找到启动的痕迹，这样就能排除模棱两可的情况。

而交易同一个品种面对的是同一张图表，大资金是怎么分辨可以买入和卖出的呢？找规律和各种技术指标，例如三推和斐波拉契，用的人多了，自然就一致的买入和卖出了。但这只是最简单的举例子，主力不可能根据一个形态结构和斐波拉契就拉盘，而是结合当下背景，配合技术分析买入卖出。

图表就这么大，不是涨就是跌，一天前发生的走势可能今天五分钟又走一遍，另一个品种的走势可能在这个品种再复现一遍，一模一样的走势也有可能走出相反的行情，我们只需要尊重概率。

我们可以复盘历史，寻找历史的交易机会，进行归纳总结，形成一套自己的开仓逻辑，

我们需要学习前人总结的规律，少走弯路，例如阿尔布鲁克斯价格行为。当出现三推下跌某个地方的时候，你能知道这是书中讲的三推回测起点。

## 怎么增加胜率？
既然有胜率，那么肯定就可以增加胜率，经过自己的学习，知道了顺势增加胜率，右侧增加胜率，阻力越少增加胜率等等

在其中做个取舍保持一个均衡即可，我自己就只做顺势，只有趋势发起后，等待回调做顺势方

还有就是突破通道线，突破通道线的前一个波段点，收回支撑区，都进入我胜率的评分系统


## 怎么增加盈亏比？
非常简单，把止损收窄，止盈放大即可。

增加盈亏比的前提是，你的止损位置被打了说明判断错误大概率不会盈利以及止盈的位置在这一笔交易有能到的概率，否则一个品种当前价格是1，你设置止损为0.99，止盈为100，虽然还是有概率到，但是完全没有必要了，就算到了也需要非常多的时间，而且胜率非常低。

设置盈利位置可以参考：等比行情，区间等比，三推回测起点，通道回测起点，斐波拉契，裸k管理等等

增加盈亏比最简单的方式就是左侧，但是本人不做左侧，所以只教右侧。

而右侧增加盈亏比的方式就是订单管理，虽然左侧也能订单管理，但是右侧更好订单管理。

例如你预测双底，在突破双底颈线的位置入场，那么它再次跌破前低就代表这个预测是错误的，此时离场是完全正确的。

## 大白话
市场一定是规律可循的，不然交易员盈利就是空谈，很多新手交易员都相信每个品种都有庄家，有些小品种是会有庄家的情况，但是我是尊崇技术分析，就算有庄家，出现亏损也当做是系统出现磨损周期而已，正常情况。

用逻辑去假设一种情况，假设每个品种都有庄家，现在有一个品种庄家想拉盘，目前市场在底部盘整区间很久了，会出现以下情况：
- 跌破区间底部再收回
- 跌破区间底部再收回 随后再次跌破
- 跌破区间底部再收回 随后再次跌破 再次收回 再次跌破
- 直接突破区间顶部一去不复返
- 直接突破区间顶部随后跌回区间继续盘整
- 直接突破区间顶部随后跌回区间随后又突破

出现的情况非常多，我就拿几个举例出来，我们用技术分析分析每种情况会怎么入场：
1. 说明是假跌破，直接入场
2. 说明是假跌破，直接入场，随后发现不是假跌破，又跌破了前低，直接离场
3. 说明是假跌破，直接入场，随后发现不是假跌破，又跌破了前低，直接离场，出现第三次假跌破的时候说明是三推，逆势方颓势，直接入场
4. 突破交易者直接入场，保守交易者踏空
5. 突破交易者止损离场，保守交易者未发生交易
6. 突破交易者会止损一次，但是最终还是和保守交易者都持有仓位

上面还是把大部分情况都列出来，而庄家并不在意是不是有人赚钱，他只是想自己赚足够多的利润，例如假跌破为了洗走持仓者，突破一去不复还为了洗走保守交易者。

由此可见，就算有庄家只要符合正期望的做单逻辑，一样能盈利。因为k线的优势是你随时可以入场和离场，你想拿多久就拿多久，这对成熟的交易者是优势，但是对没有任何交易技术的新手反而是加大亏损的导火索，有些新手拿一点盈利就走，亏损就扛着。出现盈利又拿着，反而打到止损。因为他们在迷雾重重的市场看不清胜率方在哪边，完全是在乱玩。
