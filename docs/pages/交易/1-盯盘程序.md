# 盯盘软件



## 为什么？

因为国内网络，加上有自己的工作，会出现没时间盯盘的问题，就算有时间一想到 `VPN` 网络波动出现加载图表很慢，影响分析流程性就会懒惰。

但是一个交易员如果不看盘，就根本没有交易的机会，所以就在想，有什么办法能过滤大部分系统外的行情，当初步符合系统内的行情进行提醒我密切关注，直到出现系统机会入场交易。

刚开始是通过企业微信文字提醒，但是还是要打开交易软件搜索代币，进行看盘。后面发现可以通过 `Puppeteer` 打开 <a href ="https://www.coinglass.com/tv/zh/Binance_BTCUSDT">coinglass </a> 输入指定币种进行截图推送到企业微信，这样就能节省打开软件输入代币繁琐的过程，直接来到熟悉领域，看图表判断是否符合系统内交易。

### 历史:

1. 过滤采用vegas144和288金叉，离最高点k14根后出现十字星突破 | 强外包k 进行提醒
2. 首次形成金叉并且最高点距离金叉均线位置ATR大于3.5，随后最高点7根k后触碰0.5斐波拉契进行提醒



上面两种情况都不太理想，但是还是可以过滤40%的行情了，随后我就开始思考，怎么寻找极速行情，问了ai有下面的几种方法：

- 涨幅百分比
- ATR
- 斜率
- ...



### 最终：

最终经过我复盘，总结了规律，采用以下过滤条件：



过滤条件：

1. 144 288金叉
2. 45根k线内有连续14根k组成的最低价和最高价的atr超过3.5
3. 随后寻找这波趋势的最低点以及最高点
4. 随后就是回调监控，主要是要找到最高点那根k往后数
   - 高点过后的第七根k线后来到这段高低点的38.2%位置提醒
   - 高点过后的第14根k线后来到50%提醒
   - 高点过后第28来到61.8%提醒
   - 如果在7/14/28根前就触碰了就进入下一个条件，如果都不满足就放弃
5. 需要打印参数：14根k参考时间。例如：[ 13:45-17:00 ]，高低点价格，14根k的atr是多少，回调条件是哪个

// ==================== 技术指标计算 ====================
function calculateATR(highs: number[], lows: number[], closes: number[], period: number = 14): number[] {
  let tr: number[] = [highs[0]! - lows[0]!]
  for (let i = 1; i < closes.length; i++) {
    const hl = highs[i]! - lows[i]!
    const hpc = Math.abs(highs[i]! - closes[i - 1]!)
    const lpc = Math.abs(lows[i]! - closes[i - 1]!)
    tr.push(Math.max(hl, hpc, lpc))
  }

  const k = 2 / (period + 1)
  let atr = [tr[0]!]
  for (let i = 1; i < tr.length; i++) {
    atr.push(tr[i]! * k + atr[i - 1]! * (1 - k))
  }
  return atr
}

function calculateEMA(values: number[], period: number): number[] {
  let ema: number[] = []
  if (values.length === 0) return ema
  ema.push(values[0]!)
  const k = 2 / (period + 1)
  for (let i = 1; i < values.length; i++) {
    ema.push(values[i]! * k + ema[i - 1]! * (1 - k))
  }
  return ema
}

function formatTimeHHMM(timestamp: number): string {

  const minutes = String(date.getMinutes()).padStart(2, '0')
  return `${hours}:${minutes}`
}

async function captureAndSendImage(symbol: string, content: string) {

  let page: Page | null = null

    const TARGET_CLASS = '.MuiCircularProgress-svg'
    let isPageReady = false
    const startTime = Date.now()
    const MAX_WAIT_MS = 35000

    while (!isPageReady) {
      if (Date.now() - startTime > MAX_WAIT_MS) {
        console.log(`⚠️ ${symbol} 加载超时超过 ${MAX_WAIT_MS / 1000}秒，强制执行截图。`)
        break
      }

      const hasProgress = await page.evaluate((selector) => {
        return document.querySelector(selector) !== null
      }, TARGET_CLASS)

      if (hasProgress) {
        await new Promise(resolve => setTimeout(resolve, 500))
        continue
      }

      await new Promise(resolve => setTimeout(resolve, 3000))

      const reCheckProgress = await page.evaluate((selector) => {
        return document.querySelector(selector) !== null
      }, TARGET_CLASS)

      if (!reCheckProgress) {
        isPageReady = true
      } else {
        console.log(`🔄 ${symbol} 缓冲期内再次触发加载，重新进入等待流程。`)
      }
    }

    const imageBuffer = await page.screenshot({ type: 'png', fullPage: false })
    if (!Buffer.isBuffer(imageBuffer)) throw new Error('截图未生成有效的 Buffer')

    const md5 = crypto.createHash('md5').update(imageBuffer).digest('hex')
    const base64 = imageBuffer.toString('base64')

    await axios.post(WECOM_WEBHOOK, { msgtype: "text", text: { content } }, { timeout: 10000 })
    await axios.post(WECOM_WEBHOOK, { msgtype: "image", image: { base64, md5 } }, { timeout: 10000 })
    console.log(`🚀 ${symbol} 预警文本及图片信号推送成功!`)

  } catch (e: any) {
    console.error(`❌ ${symbol} 截图或推送失败:`, e.message)
  } finally {
    if (page) { try { await page.close() } catch (e) { } }
  }
}

// ==================== 策略核心扫描 ====================
async function checkStrategy() {
  if (isLoginMode) {
    await captureAndSendImage('BTCUSDT', '测试登录模式')
    return
  }

  if (isScanning) return
  isScanning = true

  try {
    const { data: tickers } = await axios.get('https://fapi.binance.com/fapi/v1/ticker/24hr', { timeout: 10000, httpsAgent: globalHttpsAgent })

    const usdtSymbols = tickers.filter((t: any) => t.symbol.endsWith('USDT') && parseFloat(t.quoteVolume) > STRATEGY_CONFIG.VOLUME_THRESHOLD_USD)

    for (const ticker of usdtSymbols) {
      const symbol = ticker.symbol

      // 冷却阻断
      if (db[symbol]?.blacklistedUntil && db[symbol].blacklistedUntil > Date.now()) {
        continue
      }

      try {
        const hasCache = globalKlineCache[symbol] && globalKlineCache[symbol]!.length >= 350
        const currentLimit = hasCache ? STRATEGY_CONFIG.INCREMENTAL_LIMIT : STRATEGY_CONFIG.KLINE_LIMIT

        const apiRes = await axios.get('https://fapi.binance.com/fapi/v1/klines', {
          params: { symbol, interval: STRATEGY_CONFIG.INTERVAL, limit: currentLimit },
          timeout: 8000,
          httpsAgent: globalHttpsAgent
        }).then(res => res.data).catch(() => null)

        await new Promise(resolve => setTimeout(resolve, 500))

        if (!apiRes || !Array.isArray(apiRes) || apiRes.length === 0) continue

        let klines: any[][] = []

        if (hasCache) {
          const cachedData = globalKlineCache[symbol]!
          const mergedMap = new Map<number, any[]>()
          cachedData.forEach(k => mergedMap.set(k[0], k))
          apiRes.forEach(k => mergedMap.set(k[0], k))

          klines = Array.from(mergedMap.values())
            .sort((a, b) => a[0] - b[0])
            .slice(-STRATEGY_CONFIG.KLINE_LIMIT)
        } else {
          klines = apiRes
        }

        globalKlineCache[symbol] = klines

        if (klines.length < 350) continue

        const highs = klines.map((k: any) => parseFloat(k[2]))
        const lows = klines.map((k: any) => parseFloat(k[3]))
        const closes = klines.map((k: any) => parseFloat(k[4]))

        const lastIdx = klines.length - 1
        const minRequiredLength = Math.max(45, STRATEGY_CONFIG.SLOW_MA_PERIOD)
        if (lastIdx < minRequiredLength) continue

        // 🟢 【过滤条件一】：144 / 288 大周期多头金叉过滤
        const fastEma = calculateEMA(closes, STRATEGY_CONFIG.FAST_MA_PERIOD)
        const slowEma = calculateEMA(closes, STRATEGY_CONFIG.SLOW_MA_PERIOD)
        const isGoldenCross = fastEma[lastIdx]! > slowEma[lastIdx]!

        if (!isGoldenCross) continue

        // 🟢 【过滤条件二】：45根k线内，是否存在连续14根k组成的最高价和最低价的价差超过 3.5倍 ATR
        const atr = calculateATR(highs, lows, closes, STRATEGY_CONFIG.ATR_PERIOD)

        let condition14BarsMet = false
        let atrTimeRange = ""
        let matchedAtrValue = 0

        // 在过去45根K线范围（由lastIdx-44 到 lastIdx）内滑动寻找满足条件的14根K线窗口
        // 14根窗口的结束索引 i 的有效范围是 [lastIdx - 31, lastIdx]
        for (let i = lastIdx; i >= lastIdx - 31; i--) {
          if (i < 13) continue
          const recentHighs = highs.slice(i - 13, i + 1)
          const recentLows = lows.slice(i - 13, i + 1)
          const maxHigh14 = Math.max(...recentHighs)
          const minLow14 = Math.min(...recentLows)
          const currentAtr = atr[i]!

          if (currentAtr > 0 && (maxHigh14 - minLow14) / currentAtr > STRATEGY_CONFIG.ATR_MULTIPLE_THRESHOLD) {
            condition14BarsMet = true
            const startTimeStr = formatTimeHHMM(klines[i - 13]![0])
            const endTimeStr = formatTimeHHMM(klines[i]![0])
            atrTimeRange = `[ ${startTimeStr}-${endTimeStr} ]`
            matchedAtrValue = currentAtr
            break // 优先采用最靠近当前时间的满足条件的窗口
          }
        }

        if (!condition14BarsMet) continue

        // 🟢 【过滤条件三】：寻找当前波段的最高点以及对应的结构最低点
        let highestPrice = -1
        let highestIdx = -1
        const scanWindow = Math.min(STRATEGY_CONFIG.SCAN_WINDOW_BARS, klines.length)

        // 寻找扫描窗口内的最高点
        for (let i = lastIdx - scanWindow + 1; i <= lastIdx; i++) {
          if (highs[i]! > highestPrice) {
            highestPrice = highs[i]!
            highestIdx = i
          }
        }
        if (highestIdx === -1) continue

        // 从最高点往左回溯（最多45根），寻找这波上涨行情的结构最低点
        let lowestPrice = Infinity
        const startSearchIdx = Math.max(0, highestIdx - 45)
        for (let i = startSearchIdx; i <= highestIdx; i++) {
          if (lows[i]! < lowestPrice) {
            lowestPrice = lows[i]!
          }
        }
        if (lowestPrice >= highestPrice || lowestPrice === Infinity) continue

        // ==================== 🛠️ 【时间+空间防偷跑闸门判定】 ====================
        const waveHeight = highestPrice - lowestPrice
        const fib382 = highestPrice - waveHeight * 0.382
        const fib50 = highestPrice - waveHeight * 0.50
        const fib618 = highestPrice - waveHeight * 0.618

        const barsSinceHigh = lastIdx - highestIdx
        if (barsSinceHigh <= 0) continue // 当前正是最高点K线，暂不作回调监控

        let triggerAlert = false
        let alertReason = ""
        let conditionType = ""

        // 历史足迹追踪：判定在各时间闸门前，是否已经提前触碰了对应的黄金分割位
        let hasTouched382Before7 = false
        let hasTouched382From7Onwards = false

        let hasTouched50Before14 = false
        let hasTouched50From14Onwards = false

        let hasTouched618Before28 = false
        let hasTouched618From28Onwards = false

        let isStructureBroken = false

        for (let i = highestIdx + 1; i <= lastIdx; i++) {
          const barsAfter = i - highestIdx
          const histLow = lows[i]!

          if (histLow < lowestPrice) {
            isStructureBroken = true
          }

          // 38.2% 追踪
          if (barsAfter < 7) {
            if (histLow <= fib382) hasTouched382Before7 = true
          } else if (barsAfter >= 7 && barsAfter < 14) {
            if (histLow <= fib382) hasTouched382From7Onwards = true
          }

          // 50% 追踪
          if (barsAfter < 14) {
            if (histLow <= fib50) hasTouched50Before14 = true
          } else if (barsAfter >= 14 && barsAfter < 28) {
            if (histLow <= fib50) hasTouched50From14Onwards = true
          }

          // 61.8% 追踪
          if (barsAfter < 28) {
            if (histLow <= fib618) hasTouched618Before28 = true
          } else if (barsAfter >= 28) {
            if (histLow <= fib618) hasTouched618From28Onwards = true
          }
        }

        // 回调核心状态判定区
        if (!isStructureBroken) {
          if (barsSinceHigh >= 7 && barsSinceHigh < 14) {
            // 条件一：7根K线或之后来到38.2%，且前7根未提前触碰。若提前触碰则失效并自动进入对50%的监控
            if (!hasTouched382Before7 && hasTouched382From7Onwards) {
              triggerAlert = true
              conditionType = "7根K线后首触38.2%"
              alertReason = `🎯 满足 [7根K线后首触38.2%] 预警位: ${fib382.toFixed(4)}`
            }
          } else if (barsSinceHigh >= 14 && barsSinceHigh < 28) {
            // 条件二：14根K线或之后来到50%，且前14根未提前触碰
            if (!hasTouched50Before14 && hasTouched50From14Onwards) {
              triggerAlert = true
              conditionType = "14根K线后首触50.0%"
              alertReason = `🎯 满足 [14根K线后首触50.0%] 预警位: ${fib50.toFixed(4)}`
            }
          } else if (barsSinceHigh >= 28) {
            // 条件三：28根K线或之后来到61.8%，且前28根未提前触碰
            if (!hasTouched618Before28 && hasTouched618From28Onwards) {
              triggerAlert = true
              conditionType = "28根K线后首触61.8%"
              alertReason = `🎯 满足 [28根K线后首触61.8%] 预警位: ${fib618.toFixed(4)}`
            }
          }
        }

        const currentLow = lows[lastIdx]!
        const currentRetracePct = ((highestPrice - currentLow) / waveHeight) * 100

        // 👑 【全升级版·核心对账日志打印区】
        console.log(`📊 [回调预警参数对账]
    币种: ${symbol.padEnd(8)} | 距高点K线数: ${String(barsSinceHigh).padEnd(2)} | 当前最低价回调比: ${currentRetracePct.toFixed(2)}%
    [时间对账] 14K波动率计算参考时间: ⏱️ ${atrTimeRange || '未达标'} | 14K的ATR值: ${matchedAtrValue.toFixed(4)}
    [维加斯过滤] 快线EMA(144): ${fastEma[lastIdx]!.toFixed(4)} | 慢线EMA(288): ${slowEma[lastIdx]!.toFixed(4)} -> 状态: ✅ 多头排列
    [波段价格] 最高点价格: ${highestPrice.toFixed(4)} (Idx: ${highestIdx}) | 最低点价格: ${lowestPrice.toFixed(4)}
    [目标水位] 38.2%位: ${fib382.toFixed(4)} | 50%位: ${fib50.toFixed(4)} | 61.8%位: ${fib618.toFixed(4)}
    [防偷跑校验] 7根前触发382: ${hasTouched382Before7 ? '❌(已偷跑)' : '✅'} | 14根前触发50: ${hasTouched50Before14 ? '❌(已偷跑)' : '✅'} | 28根前触发618: ${hasTouched618Before28 ? '❌(已偷跑)' : '✅'}
    [策略状态] 结构完好性: ${isStructureBroken ? '⚠️ 趋势结构已破坏' : '✅ 正常'} | 触发条件: ${triggerAlert ? `🚨 ${conditionType}` : '❌ 暂未触发'}\n`)

        if (triggerAlert) {
          // 封装企业微信通知文本
          const wecomNoticeText = `⚠️【回调预警触发信号】\n` +
            `币种: ${symbol}\n` +
            `周期: ${STRATEGY_CONFIG.INTERVAL}\n` +
            `触发回调条件: ${conditionType}\n` +
            `14根K线参考时间: ${atrTimeRange}\n` +

## 核心流程极简梳理

每一轮扫描（5分钟/次），K线数据必须严格连过以下五关：

### 1. 趋势清洗（EMA 过滤）

- **门槛**：24小时成交额 **> 1,000万刀**，且该币种不在4小时报警冷却期内。
- **核心**：必须满足 **`EMA144 > EMA288`**（大周期刚性多头排列），死叉形态直接淘汰。

### 2. 动能抓取（45K内连续14K异动）

- **核心**：在最近 **45根 K线**的大范围内滑动检查。
- **指标**：必须存在某段**连续14根 K线**，其 `最高价 - 最低价 > 3.5 * ATR`。
- **锁定**：一旦捕获成功，立刻记录该 14 根 K线的**参考时间段**（如 `[13:45-17:00]`）和 **ATR 值**。

### 3. 波段定锚（确立高低点）

- **定高点**：锁定扫描窗口内的绝对最高价（`highestPrice`）。
- **定低点**：从最高点**向左回溯最多45根 K线**，找出这波暴涨起点的绝对最低价（`lowestPrice`）。
- **空间**：以此两点确立斐波那契（38.2% / 50% / 61.8%）的垂直价位空间。

### 4. 时空双校对（防偷跑矩阵）

从最高点那根 K线往后数数量（设为 `N`），严格执行以下对账：

- **38.2% 预警**：必须在 **`N >= 7` 根**时才首次触碰。若在 1-6 根内提早跌破，此条件作废。
- **50.0% 预警**：必须在 **`N >= 14` 根**时才首次触碰。若在 1-13 根内提早跌破，此条件作废。
- **61.8% 预警**：必须在 **`N >= 28` 根**时才首次触碰。若在 1-27 根内提早跌破，此条件作废。
- 🚨 **一票否决**：回调期间一旦最低价跌破波段起点 `lowestPrice`（结构砸穿），直接放弃监控。

### 5. 精准收网（打印与推送）

- **对账**：后台实时打印 14K参考时间、高低点价格、ATR值、触发哪个回调条件。
- **风控**：写入本地缓存，该币种强行进入 **4小时全局冷却**（防重复轰炸）。
- **推送**：后台异步唤醒 Chrome 浏览器渲染交易图表并**截图**，企业微信连发两条通知（**对账文字参数 + 走势截图**）。
